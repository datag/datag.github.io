Privacy Policy

Last updated: 25 October 2026

1. General

This is a purely private, non-commercial website on which I publish open-source hobby projects and mini-games. As the operator of this site, I do not collect, process, or store any personal data, and the site contains no advertising.

This policy applies to the entire datag.is-a.dev domain, i.e. to these pages as well as to the demo applications that I host under it.

These pages set no cookies and write nothing to your browser's local storage. The demo applications hosted under the same domain do store data in your browser (section 3). Delivering the site technically involves third-party infrastructure, which is described in section 2.

2. Hosting and delivery

GitHub Pages

The website is hosted on GitHub Pages, a service of GitHub, Inc. (88 Colin P Kelly Jr St, San Francisco, CA 94107, USA). When you access this site, GitHub automatically collects and stores server log files (e.g., your IP address, browser type, operating system, and time of access). This data is processed by GitHub as the hosting provider and is technically necessary to deliver the website securely and reliably (Article 6(1)(f) GDPR — legitimate interest).

The domain and the Cloudflare proxy

The site is addressed at datag.is-a.dev, a subdomain of the free is-a.dev project. The DNS zone of the is-a.dev project is operated by Cloudflare, Inc. (101 Townsend Street, San Francisco, CA 94107, USA). The entry for datag.is-a.dev is configured as a proxied record rather than as a plain DNS record, so every request first reaches a Cloudflare server and is forwarded from there to GitHub Pages.

Cloudflare processes the connection data of each request (e.g., IP address, browser type, operating system, time of access, and the requested URL) in order to route, cache, and protect the site against attacks (Article 6(1)(f) GDPR — legitimate interest). In addition, Cloudflare injects its own scripts into the HTML response of this site:

  • an analytics script (Cloudflare Web Analytics), which transmits page views, the referrer, the approximate location (country/region) derived from the IP address, browser and device information, and page load times to Cloudflare;
  • a script that obfuscates e-mail addresses in the page source;
  • a script used for bot detection.

These scripts do not set cookies and do not store anything in your browser (as of the date shown above). Cloudflare processes this data in the United States. The configuration of the proxy is determined by the is-a.dev project and is outside my control; I will update this policy if it changes.

3. Cookies and data stored in your browser

These pages set no cookies and write nothing to your browser's local storage. The third-party services described in section 2 do not set cookies either (as of the date shown above). Because no information is stored on or read from your terminal equipment when you view these pages, they display no consent banner.

The demo applications hosted on this domain do store data in your browser's local storage, for example game progress, settings, a user name and avatar, and — if you enter one — an OpenAI API key for the AI-assisted text generation of some of the applications. The applications run entirely in your browser: this data is never transmitted to me or to any server of mine. The API key and the text you enter are sent directly from your browser to OpenAI, and only when you actually use that feature. Each application documents the details in its own documentation.

4. Contact

If you have any questions about this privacy policy, you can contact me via my GitHub profile or by email: dominik.geyer@gmail.com.

You also have the right to lodge a complaint with a data protection authority, for example the Bavarian Data Protection Authority (BayLDA).

Die Domain und der Cloudflare-Proxy
